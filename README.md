# 古代冰淇淋店的客人

林亞澤各部作品的角色，換上古裝的 Q 版人設，附古代職業、人設與三種反應台詞（打招呼、拿到滿意的冰淇淋、拿到不滿意的冰淇淋）。給茶葉飲料的古代冰淇淋店 3D 小遊戲挑顧客用。

網頁：https://yazelin.github.io/chibi-time-travelers/

網頁上可以勾想要的角色、挑台詞，最下面會整理成一段文字，複製貼到 Larch 回覆。

## 檔案

| 路徑 | 內容 |
|---|---|
| `characters.json` | 所有角色的資料（唯一來源）：名字、作品、職業、人設、台詞。頁面直接讀這份 |
| `img/<id>.webp` | 頁面顯示用的小圖（寬 480） |
| `img/full/<id>.webp` | 原尺寸大圖，做 3D 時參考 |
| `tools/add_image.py` | 把產好的 PNG 轉成上面兩張 WebP，原圖不進 repo |
| `tools/check.py` | 發布前檢查：圖只准 WebP、每個角色都有圖和三種台詞；CI 每次推送都會跑 |

## 加一個角色

1. `python3 tools/add_image.py <id> <產好的圖.png>`
2. 在 `characters.json` 加一筆，id 跟圖一致
3. `python3 tools/check.py` 通過再推
